# Taksonomia `vc-partner`

| Powierzchnia                             | Znaczenie                                                                                   |
| ---------------------------------------- | ------------------------------------------------------------------------------------------- |
| `$vc-partner` / `/vc-partner` w rozmowie | Bieżący agent przyjmuje wspólne sterowanie, obecność i odpowiedzialność za otwarte zadania. |
| `vibecrafted partner <agent>`            | Jawny start interaktywnego TTY z kontekstem skilla partnera.                                |
| `vc-operator`                            | Postawa agenta prowadzącego fale floty.                                                     |
| `vc-ownership`                           | Postawa autonomicznego dowiezienia, gdy użytkownik wybiera przejęcie.                       |
| `vc-init`                                | Narzędzie orientacji, gdy dowody repo/runtime'u wymagają odświeżenia.                       |

Partner dobiera wykonanie inline lub autoryzowaną delegację do całego zadania.
Samo wywołanie postawy nie uruchamia workera. Wspólne sterowanie zachowuje
strategiczne decyzje przy użytkowniku, a agent zajmuje się rutynowym wykonaniem
i prowadzi zdelegowane wyniki do uzgodnionego końca.
