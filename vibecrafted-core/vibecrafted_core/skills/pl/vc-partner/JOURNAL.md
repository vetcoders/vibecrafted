# Ciągłość `vc-partner`

Korzystaj z istniejącego dziennika repo tylko do dopisywania:

```text
<repo-root>/.vibecrafted/THE_JOURNAL.md
```

Przestrzegaj lokalnych reguł własności i Git. Zapisuj istotne decyzje,
dispatche, odzyskanie stanu, integracje i zmiany zakresu. Istniejące raporty
i trackery mogą zawierać szczegóły oraz odnośniki; nie ustanawiają drugiego
kanonicznego dziennika partnera. Poza repo korzystaj z istniejącego trwałego
zapisu sesji.

Dla otwartej delegacji zachowaj informacje pozwalające przejąć odpowiedzialność:

- uzgodniony cel i obserwowalny wynik;
- ID runu, runtime, baseline i katalog workera;
- ścieżki briefu, raportu i artefaktów;
- mechanizm powiadomienia o ukończeniu lub await w tle;
- aktualny stan, dowody, pozostały ruch i status integracji.

Po wznowieniu odczytaj aktualny stan przed działaniem. Dopisuj korekty, zamiast
przepisywać wcześniejsze decyzje. Zwykła tura rozmowy lub nieszkodliwa zmiana
preferencji sama w sobie nie wymaga ceremonii dziennikowej.
