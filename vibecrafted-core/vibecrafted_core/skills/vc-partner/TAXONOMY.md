# `vc-partner` Taxonomy

| Surface                                       | Meaning                                                                           |
| --------------------------------------------- | --------------------------------------------------------------------------------- |
| `$vc-partner` / `/vc-partner` in conversation | Current agent adopts shared steering, presence and responsibility for open tasks. |
| `vibecrafted partner <agent>`                 | Explicit interactive TTY launch seeded with the partner skill.                    |
| `vc-operator`                                 | Agent posture for conducting fleet waves.                                         |
| `vc-ownership`                                | Autonomous delivery posture when the user chooses a takeover.                     |
| `vc-init`                                     | Orientation tool used when repo/runtime evidence needs refreshing.                |

The partner chooses inline work or authorized delegation according to the
whole task. Invoking the posture alone launches no worker. Shared steering
keeps strategic decisions with the user while the agent handles routine
execution and follows delegated results through to the agreed outcome.
