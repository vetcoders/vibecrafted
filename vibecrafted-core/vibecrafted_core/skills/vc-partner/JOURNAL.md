# `vc-partner` Continuity

Use the repository's existing append-only journal:

```text
<repo-root>/.vibecrafted/THE_JOURNAL.md
```

Follow its local ownership and Git rules. Record material decisions,
dispatches, recoveries, integrations and scope changes. Existing reports and
trackers can hold details and link back; they do not establish a second
canonical partner journal. Outside a repository, use the session's existing
durable record.

For open delegated work, retain enough information to resume responsibility:

- agreed purpose and observable result;
- run ID, runtime, baseline and worker root;
- brief, report and artifact paths;
- completion notification or background await mechanism;
- current status, evidence, remaining action and integration disposition.

On resume, re-read the current state before acting. Append corrections rather
than rewriting previous decisions. A normal conversational turn or harmless
preference change does not itself need a journal ceremony.
