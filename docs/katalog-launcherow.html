Anatomia wywołania

Deck ma trzy bramy. Każdy skill instaluje też skrót vc-<skill> — cienki wrapper, który przekazuje argv w całości.

vibecrafted <command> [args]                       # komenda decka (init, doctor, server…)
vibecrafted <skill> <agent> [-p <prompt> | -f <file>]  # workflow z agentem zewnętrznym
vibecrafted <agent> <mode> <plan.md>                 # tryb plan-based per agent
vc-<skill> <agent> [flags]                          # skrót; identyczny kontrakt

Agenci: claude · codex · agy · junie · grok · cursor (gemini przyjmowany, zdeprecjonowany na rzecz agy).

Kontrakt flag — wspólny dla wszystkich skilli

Karty niżej nie powtarzają tych flag; wymieniają tylko odchyłki od kontraktu.

-p, --prompt <text>prompt inline -f, --file <path.md>plik wejściowy jako kontekst zadania (wskaźnik, nie payload w argv) --prompt-stdinprompt ze stdin; zero kopii w argv/tmp --runtime <terminal|headless>powierzchnia workera (domyślnie: headless) --root <path>root repozytorium --model <name>override modelu agenta --jsonmaszynowy launch receipt --count <n>rundy pętli (marbles / polarize; domyślnie 3) --depth <n>głębokość crawl planu (marbles; domyślnie 3) --verboseglobalnie: szczegółowy output

Ship-cycle — 11 etapów w kolejności kanonicznej

scaffold → implement → review → workflow → followup → marbles → audit → polarize → dou → hydrate → release

Rytm READ/WRITE: etapy czytające budują dowód, etapy piszące tną. decorate (WRITE 2.1.0) wchodzi między dou a hydrate, gdy powierzchnia wymaga wykończenia wizualnego. Parasol całości: vc-ship.

vibecrafted init [claude|codex|agy|junie|grok|cursor]
vc-init [agent]

resume MGMT

Trzy tryby: wznowienie zatrzymanego runa control-plane, natywne wznowienie sesji providera, albo pakiet ciągłości AICX (48 h) bez id.

vibecrafted resume <agent> --run-id work-…
vibecrafted resume <agent> --session <uuid>
vibecrafted resume <agent>        # AICX pack
vc-resume …

Flagi: --last, -p/-f, --fork-session (tylko claude). Nigdy work-* ani VIBECRAFTED_SESSION_ID do --session. Okno AICX: VIBECRAFTED_RESUME_AICX_HOURS.

Dzisiejsza aktywność agentów.

vibecrafted status    # alias: stats

Powierzchnia operatora

dashboard OPS

Cienki shim nad natywnym vc-frame: sesje operatorskie i layouty.

vibecrafted dashboard [layout]
vibecrafted dashboard ls|switch|attach|kill <name>
vibecrafted dashboard gc [--apply]
vibecrafted start     # alias dashboard

Layouty: dashboard (domyślny) · marbles · workflow · research · operator.

loop OPS

Interaktywna kontynuacja Agent-Operatora + łańcuchy async await po workerach.

vibecrafted loop start --prompt|--file …
  [--completion-promise READY]
vibecrafted loop next | status | complete --promise
vibecrafted loop await-run --run-id <id>
  --then-cmd '<next dispatch>'

Stan: <repo>/.vibecrafted/operator-loop.local.md. --then-cmd nigdy push/deploy bez planu.

cron OPS

Cron-safe heartbeat pętli: łapie kontekst Loctree+AICX, wznawia zatwierdzoną komendę po oknie idle.

vibecrafted cron tick [--root] [--after-idle-minutes 10]
  [--then-cmd <cmd>]
vibecrafted cron line [--every-minutes 10] …

tick odmawia hard-stopów: push, deploy, publish, release, reset, rm -rf…

dispatch OPS

Deterministyczny supervisor planów vibecrafted.dispatch.v1 (TOML) + async lifecycle jednego workera.

vibecrafted dispatch <plan.dispatch.toml>
  [--doctor|--dry-run|--json|--resume <run-id>]
vibecrafted dispatch run --run-id <id> --root <p>
  --report <p> --transcript <p> -- <cmd> [args]

server OPS

Lokalny serwer viewera control-plane + jego guardian; serwis trwały przez launchd (macOS).

vibecrafted server [start|stop|status|open|doctor]
vibecrafted server service
  [install|start|stop|status|uninstall]

Flagi: --port/-p (3024) · --host/-h (127.0.0.1).

gui · tui OPS

GUI: localhost-owy pythonowy control plane. TUI: rustowy kokpit voc nad wspólnym stanem.

vibecrafted gui [--source] [--host] [--port]
  [--no-open] [--bundle-dir]
vibecrafted tui [voc flags…]   # binarka: voc
voc [--state-root] [--deck] [--runtime] [--tick-ms]

telemetry OPS

Smoke ścieżki telemetrii marbles przez zainstalowany deck.

vibecrafted telemetry smoke [--agent <a>]
  [--count <n>] [--root <p>] [--no-watch|--watch]

ship OPS

Start pętli VC-Ship i dispatch checkpointu — parasol 11-etapowego lifecycle'u z supervisorem.

vibecrafted ship [args]
vc-ship <agent> --prompt "Run the full lifecycle"
