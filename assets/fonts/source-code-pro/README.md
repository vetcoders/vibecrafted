# Source Code Pro

Unmodified normal and italic variable TrueType fonts, version 1.026, copyright
2023 Adobe. Both files retain the Reserved Font Name `Source` and their embedded
OFL 1.1 metadata. Redistribution notice: [OFL.txt](OFL.txt).

Upstream: https://github.com/adobe-fonts/source-code-pro
License source: https://github.com/adobe-fonts/source-code-pro/blob/release/LICENSE.md

The terminal process carries these fonts privately through
`ATSApplicationFontsPath`. No login-session or system font registration occurs.
Source Code Pro provides Regular/Bold and Italic/Bold Italic through its weight
axis. The product asks for the named styles at 19.5 pt with native metrics.
